# Generate Documentation

1. Analyze the codebase structure
2. Review existing documentation to understand the repository's documentation style and conventions
3. Identify undocumented or poorly documented code
4. Generate comprehensive documentation following the repository's existing conventions:
   - Function/method docstrings
   - Module/class documentation
   - README sections
   - API documentation
   - Usage examples
5. Follow language-specific documentation conventions
6. Match the tone, format, and structure of existing documentation in the repository
7. Create or update relevant documentation files
